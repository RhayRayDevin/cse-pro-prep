## How to Install on Your Phone

1. Open the live site (or open `index.html` locally)
2. On **Android (Chrome)**: Menu ⋮ → **Add to Home screen** / Install app  
3. On **iOS (Safari)**: Share → **Add to Home Screen**
4. Launch the icon — it works offline
