# CSE Professional Prep

**Offline Civil Service Exam (Professional Level) trainer**

- **Exam Date:** Sunday, 22 November 2026
- **Testing Site:** Makati University
- **Passing Score:** 80%

## Features

- Live countdown to exam day
- Daily Diagnostic (10 questions × 4 categories)
- Practice modes: 40 / 80 / 120 / 150 questions
- Adaptive focus on weak areas
- Instant explanations + fun facts
- Progress tracking (daily / weekly)
- Fully offline Progressive Web App

## How to use

1. Open the live site (after enabling GitHub Pages) or open `index.html` locally
2. On phone: Chrome/Safari → Add to Home Screen
3. Practice daily!

## Categories

- Numerical Ability
- Verbal Ability (English)
- Analytical Ability
- General Information (Constitution, RA 6713, Environment)

Good luck on 22 November 2026!
